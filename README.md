# Ditto Faces

Based on pokeemerald-expansion's upcoming branch (`efced1d62c80a024497ad301430fdf31bf3e019a`, Dec 3rd 2025).

Compatible with Expansion 1.14.1.

- Adds new fields to `gSpeciesInfo` to add support for Ditto-specific graphics for each species.
- Updated Pokémon Sprite Visualizer to check Ditto sprites (cycle with Select along gender differences)
- Notes:
  - There's no current support for gender-specific Ditto versions.
  - This applies to all transformed mon, not just Ditto.

# Families supported currently:
- Bulbasaur
- Doduo
- Growlithe
- Clefairy
